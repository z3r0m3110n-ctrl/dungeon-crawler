# Dungeon Crawler RPG

Welcome to my first game! This is work-in-progress dungeon crawler RPG built with the Godot Engine. This project is an opportunity to develop my skills in game development, programming, pixel art, animation, and level design while gradually building a functional 2D dungeon crawler RPG. 

Thanks for checking out the project. More updates will follow as development continues. Your feedback is always appreciated!

## Download and Play

A Windows build of the Dungeon Crawler RPG is available for download.

- Go to the [Latest Release](https://github.com/z3r0m3110n-ctrl/dungeon-crawler/releases/latest) page.
- Download the Windows .exe file from the release assets.
- Run the executable to start the game.

Note: This is an early prototype. Some features are still under development

### Controls

| Key | Action |
|---|---|
| Arrow Keys | Move the player |
| Z | Attack |


### Releases
- [Initial Release](https://github.com/z3r0m3110n-ctrl/dungeon-crawler/releases/tag/v0.1.0): Established the foundation of the game, including player movement, idle and walking animations, a state machine, custom terrain, and collision detection.
- [Combat & Exploration Update](https://github.com/z3r0m3110n-ctrl/dungeon-crawler/releases/tag/v0.2.0): Introduced player attacks, basic combat mechanics, destructible barrels, sound effects, improved animations and collision, expanded environments, and camera and player movement boundaries.
- [An New Enemy: The Shade](https://github.com/z3r0m3110n-ctrl/dungeon-crawler/releases/tag/v0.3.0): Introduced the first enemy, the Shade, featuring custom-designed sprites, idle and walking animations, and basic AI. The Shade can wander around the environment, detect and chase the player, and switch between wandering, chasing, and attacking states. Added enemy health, hit particle effects, and new sound effects, including a hissing sound when the Shade encounters the player. Also added a sound effect for destroying barrels.

## Current Status

The current version includes:
- Player movement and idle/walking animations.
- Basic combat and attack detection.
- The Shade enemy with wandering, chasing, and attacking AI states.
- Enemy detection and pursuit behavior.
- Variable enemy health.
- Enemy hit particle effects.
- Destructible environmental objects.
- Sound effects for combat and environmental interactions.
- An expanded environment for exploration, requiring the player to navigate around obstacles.
- Basic camera and player movement boundaries.

Please see the release notes for more details.

## Built With
- Godot Engine — Game engine used for development.
- GIMP — Used to create custom terrain textures.
- Blender — Used to create the 3D model for the Shade enemy and prepare its sprite artwork.
- itch.io — Source of open-source sprites and sound effects.
- GDScript — Used to implement movement and animation state management.





## Art and Assets

The project uses custom terrain textures created in GIMP, as well as open-source sprites and sounds sourced from itch.io. The Shade enemy was developed using a [3D model created in Blender](https://lapse.hackclub.com/timelapse/81Ign89WztEN), which was used to produce posed images for sprites and animations.
